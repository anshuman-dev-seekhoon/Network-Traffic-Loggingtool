# # 🔐 Network Traffic Logging & Secure Communication Analysis Tool

## 🚀 Project Overview
In this hands-on project, I built a **Network Traffic Logging Tool** designed to capture, decrypt, and analyze encrypted communications. The tool leverages `tcpdump` for capturing raw packet data and utilizes **SSL/TLS session key logging** to enable detailed traffic decryption and analysis via **Wireshark**.

## 🛠️ Tools & Technologies Used
- **tcpdump** – for capturing encrypted traffic
- **Wireshark** – for decryption and analysis of packets
- **Firefox** – with SSLKEYLOGFILE enabled for session key logging
- **Linux terminal** – for scripting and monitoring

## 📌 Key Features
- Captured real-time network traffic on secure channels (HTTPS).
- Configured and extracted **SSL/TLS session keys** using browser-level key logging.
- Decrypted and interpreted encrypted traffic using **Wireshark’s session key settings**.
- Analyzed **application-level protocols** (e.g., HTTPs payloads).
- Verified data confidentiality and encryption techniques.

## 📂 Project Highlights
- Implemented **end-to-end encrypted traffic capture and analysis** pipeline.
- Gained real-world experience in identifying secure vs insecure communications.
- Explored **packet structures, handshake mechanisms, and encryption flows**.
- Understood how session key logging aids in packet decryption.

## 🎯 Skills Gained

- Encrypted Traffic Analysis
- Packet Analysis using Wireshark
- SSL/TLS Protocol Deep Dive
- Session Key Extraction & Use
